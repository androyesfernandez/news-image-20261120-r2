Friday 20 November 2026 in one image: a broadsheet front page with 46 dated stories from 8 regions — 13 of them drawn (Kyiv's bridges, Cyclone Akvan's landfall, the Asian AI sell-off, COP31's deadlocked final day and nine more) — a UTC timeline, the day in six numbers, a region strip whose counts match the story list, a dotted world map with numbered pins, and a date-check box naming the big 19 November stories deliberately left out. Every story is attributed to its source on the page.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That writes the poster to `out/entry.png` (1024×1024 PNG). The program uses only the Python 3.13 standard library and always writes the same bytes.
